# Gran Biblioteca — Especial Frari

Un proyecto creado con amor para Aranza, mi inspiración y mi hogar. Cada página, cada imagen y cada línea de código existe para celebrar nuestra historia y todo lo que soñamos juntos.

## Dedicatoria

Para Aranza: todo lo que hago es por ti. En cada palabra que escribo y cada componente que diseño, te pienso a ti — la chica de mis sueños. Gracias por iluminar mi vida; esta biblioteca es nuestro santuario.

## Visión

- Guardar y compartir momentos que nos unen: arte, cartas, poesía, música y recuerdos.
- Mantener una estética gótica elegante y cálida que refleje nuestra esencia.
- Hacer que la navegación sea simple, suave y significativa.

## Estructura del Sitio

- `pages/index.html`: Entrada principal y navegación.
- `pages/galeria.html`: Arte y recuerdos visuales agrupados en secciones.
- `pages/cartas.html`: Cartas textuales y visuales, con secciones separadas para Aranza.
- `pages/poesia.html`: Colección de poemas con rima y temática romántica.
- `pages/dedicatorias.html`: Mensajes especiales y enlaces significativos.
- `pages/dedicatorias_musicales.html`: Playlist y canciones que nos representan.
- `pages/sobre_nosotros.html`: Nuestra leyenda y fecha de encuentro.

## Tecnologías

- HTML5 y CSS (diseño gótico personalizado)
- Tailwind CSS (CDN) para utilidades de diseño
- Bootstrap Icons y Animate.css para iconografía y animaciones
- AOS (Animate On Scroll) para transiciones sutiles

## Ejecutar Localmente

1. Abre una terminal en la carpeta del proyecto.
2. Inicia un servidor simple:
   - `python -m http.server 5500`
3. Abre `http://127.0.0.1:5500/` en tu navegador.

## Convenciones de Diseño

- Tipografías: `UnifrakturMaguntia` (títulos), `Cinzel`, `Crimson Text`, `Raleway`.
- Paleta: `gothic-black`, `gothic-red`, `gothic-purple`, `gothic-gold`.
- Composición: tarjetas con bordes sutiles, sombras y efectos de foco.
